# v0.1 pre-Python qualification

## Frozen feature scope

This phase qualifies the existing C++20 engine and stops before Python bindings or package infrastructure.

| In scope for v0.1 | Qualification |
|---|---|
| Two-body gravity, J2 | Analytical Kepler, independently configured Tudat and DOP853; fixed J2000 +Z J2 axis |
| Full 13-state orbit/rigid-body propagation | Complete common-time trajectories and fixed-state RHS/load comparisons |
| Torque-free attitude, gravity-gradient torque | Analytical rotations/top solutions, invariants and independent numerical equations |
| SRP, cylindrical/conical eclipse, simplified albedo | Matched-equation loads and independent eclipse geometry |
| Exponential atmosphere, flat-plate/cold-beam Sentman drag | Matched-equation independent Python reference |
| Independent force/torque selection | Selected contributions checked independently |
| Adaptive integration, single/in-process batches | Existing production integrator and scheduler; complete-state determinism checks |
| Orbital analysis and trajectory export | Existing analytical and export regressions retained |

NRLMSISE-00 and JB2008 remain optional C++ implementations with their existing tests. They are **deferred to v0.2.0** and excluded from v0.1 qualification and future v0.1 packaging. No atmospheric models, integrators, caches or process-execution frameworks are introduced.

Historical numerical-audit, atmosphere, benchmark and MT-002 evidence remains immutable. In particular, CASE-C's fully coupled six-hour solution remains numerically unresolved: it is not a universal release gate. Its shorter horizons must be justified independently; no solver or tolerance changes may conceal this limitation.

## Reference and acceptance protocol

1. Correct and independently check reference equations, state/frame conventions and analytical invariants.
2. Measure reference convergence without comparing it to the C++ candidate.
3. Freeze scenario-specific acceptance limits and their justification in `tests/reference/ACCEPTANCE.md`.
4. Run fixed-state and full-trajectory acceptance at the frozen limits.
5. Benchmark only equivalent physical models at independently verified accuracy. Report unmatched or unsupported Tudat models explicitly.

The initial engineering targets are sub-metre gravity-only trajectories, approximately 1 m / 0.01 degrees on qualified six-hour CASE-A/B, and tighter pointwise loads with absolute floors near zero. Existing audit evidence can justify tighter limits; no limit is relaxed merely because a candidate fails.

Missing environmental data yielding plausible wrong loads, material disagreements on qualified scenarios, incorrect exception handling, and batch corruption/nondeterminism are release blockers. Documented physical approximations and the unresolved six-hour CASE-C stress result are scientific limitations, not automatically release blockers.
