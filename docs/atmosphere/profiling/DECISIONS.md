# Experimental decisions

Values are the implemented experiment, not defaults recommended for an eventual optimisation. Measurements and verification results are in `evidence/`.

| Choice | Actual value | Alternative | Reason / limitation |
|---|---|---|---|
| Scientific provenance | Current source SHA recorded in manifest; direct-v2 science; direct-v1 timing historical only | Treat inherited timings as fresh baseline | Avoid unsupported controlled-speedup claims |
| Production instrumentation | None; standalone generated diagnostic translation units | Add opt-in macros throughout production | Original production sources and default builds remain byte-for-byte unchanged |
| Generation | Exact unique source anchors, fail closed, original-source SHA256 record | Unchecked text patches or manually copied algorithm | Source drift must be visible; same calculation statements retained |
| Primary profiler | In-process steady-clock boundary timers plus prepared-input microbenchmarks | Sampling only | Individual midnight/SPICE/lock calls need attribution; perf absent on host |
| Wall timer | `std::chrono::steady_clock`, ns | rdtsc cycle conversion | Monotonic, portable frequency-independent time; timer overhead quantified |
| CPU timer | `CLOCK_PROCESS_CPUTIME_ID` per batch | Per-call thread CPU clock | Per-call CPU clock too intrusive; batch CPU is not pure compute nor pure wait partition |
| Calibration | 20000 clock pairs; five 10000-iteration empty sink and full-enumeration empty instrumentation controls | Subtract one median everywhere | Raw timer-inclusive values retained; instrumentation changes execution context as well as adding timers |
| Stage storage | Caller-owned thread-local fixed Record; preallocated request/row vectors | Dynamic trace map / log every call | No allocation/JSON/I/O in provider timer; capture bookkeeping remains in total RHS/propagation timing |
| Source stage checkpoints | Wall intervals between resets of local Timer; whole-provider Scope | Time every instruction | Nested function attribution; tiny stages have a timer-resolution floor |
| Compiler | GCC C/C++13.3 and GNU Fortran13.3; Release `-O3 -DNDEBUG`, C++20, no fast-math | Debug, clang, aggressive floating transformations | Match current baseline toolchain and avoid changing scientific arithmetic |
| Fixed probe | 2003-10-30T00:00:00, WGS84 45°N/30°E/400km | One arbitrary J2000 Cartesian point | Reproducible ordinary LEO case, weather storm baseline coverage |
| Fixed batches | Five ×2000 samples, 256 warm-up calls per batch | One long mean | Independent batch variability and per-request tails retained |
| Prepared microbenchmarks | Five batches ×100 timed groups;1024 operations/group for empty/validation/matrix,32 for other operations;256 warm-up calls | Individual tiny-operation timing | Amortise timer cost; empty std::function dispatch remains in operation cost; compiler memory barriers and result sinks prevent elimination |
| Geodetic distribution | Equator,45°,89.999°,exact Cartesian pole,400km; full solver and iteration counts | Latitude only or assuming fixed iterations | Includes polar shortcut and iterative convergence variability; four prepared cases are diagnostic, not an orbit distribution |
| SPICE primitives | Separate raw `pxform_c`, `et2utc_c`, both `str2et_c`, `spkez_c` prepared experiments; single thread; wrapper error preparation outside raw timing | Remove locks from provider | Raw primitive attribution without touching thread protections; wrapper timings include locks and error checks |
| NRL switches | [0,1,…,1], switch9=1 baseline; switch9=-1 separately labelled history experiment | Change baseline to history mode | Preserve established daily-Ap configuration and native cgs→SI conversion |
| CASE workload | A/B/C; both models; production Dopri5;21600s,30s output; three repetitions | Replay fixed trajectory or shorten CASE-C | Capture actual model-dependent adaptive RHS sequences, including repeated stages/rejected attempts |
| Numerical settings | rtol1e-10; max step15s; initial1s; defaults atol1e-3m/1e-6m/s/1e-12/1e-12rad/s; max attempts1e6 | Faster tolerances | Frozen numerical settings unchanged |
| Scientific control | Original experiment `execute()` no-capture nominal run per case/model; same binary arithmetic; original vs diagnostic fixtures/native/provider and full series comparison | Tests alone | Measure capture inflation and prove actual changed diagnostic surface preserves outputs |
| Controlled locality | Ten deterministic schedules ×1024 fresh calls ×both models ×three batches | Simulated cache hits | Measure exact input locality; no cache, no density interpolation; real UTC metadata acquired after timed loops |
| Weather-isolation schedule | One UTC date with changing epoch and grid position |128-day sweep mislabelled identical records | Isolate same daily record identity; JB hourly interpolation can still vary |
| Boundaries | Hourly/three-hour sweeps separate from midnight; real utc_calendar fields validate actual bins | ET/86400 date arithmetic | Avoid UTC/TDB-rate/leap-day mistakes in locality conclusions |
| Ensemble | Eight independent nearby trajectories ×128 epochs, trajectory-major and epoch-major; explicit captured trajectory IDs | Position-proximity clustering | Same request set, different ordering; no invented trajectory membership |
| Exact keys | IEEE754 bits of ET,x,y,z, no rounding, +0/−0 distinct | Quantised times/coordinates | Only unchanged-input reuse is exact; near inputs require numerical approximation |
| Quantiles | Stages: nearest-rank p95/p99, conventional median; workloads: linear interpolation at q(n−1) | One undocumented estimator | Both raw data and estimator retained; do not compare tails as identical estimators |
| Stage reconciliation | Same-request exclusive segment means against inclusive provider mean; inclusive children not summed twice | Difference of independent medians | Instrumentation/wrapper residual explicitly measured, not falsely assigned to a function |
| CPU affinity | Single-thread measurements CPU0; stage process allowed0–3, main pins0 until concurrency then restores0–3; workloads taskset0 | Unpinned, whole machine, fixed dedicated cores | Reduce migrations while allowing actual multi-thread concurrency; no guarantee of physical-core isolation under WSL |
| Concurrency |1/2/4 workers, barriers after all256-call warm-ups;five batches;both fixed and 0.01s-step varying epochs,tid offset0.001s | Delete locks / assume native reentrant | Quantify protected implementation as it exists; diagnostic timers inside locks inflate hold time, so original throughput control required |
| Host frequency | No governor/current-frequency sysfs files; load recorded before/after | Force performance governor | WSL2 exposes neither control; host scheduling and boost variation remain limitations |
| Sampling cross-check | `perf` executable absent, recorded failure | Claim unsupported cycle/callgraph data | Independent microbenchmarks are the available cross-check; no invented sampling result |
| Evidence retention | Raw request JSONL, raw timings, summaries, SHA256; gzip large raw evidence | Keep only averages or overwrite baselines | Reproducible reanalysis; historical direct-v1/v2 and amendment trees verified unchanged |
| Opportunity estimates | Amdahl removal ceilings using measured fractions; full propagation fractions from actual calls/wall | Predict cache throughput from reuse counts | No lookup/memory/synchronisation cost measured; ceilings are not measured speedups or expected cache performance |
| Exploratory contention supplement | Native-only and each SPICE wrapper separately; external Sun+provider;7 workloads ×1/2/4 workers ×5 batches ×2000 calls/worker | Only full-provider contention | Separate native serialization from shared-SPICE contention and traffic elsewhere in RHS; supplementary selection followed primary results |
| Independent fixture execution | Direct existing native-reference test filters, console assertion counts, explicit no-skip requirement | Treat CTest returncode as proof fixtures were not skipped |17 published NRL,13320 official JB grid and12 full-precision JB cases actually execute; pre-existing reference residuals retained |
| Post-processing correction | Preserve `.jsonl.gz` suffix; normalise accidental nested gzip wrappers; retain uncompressed SHA256s | Discard traces or rerun physics to hide a storage defect |Compression wrappers only changed, not any request values; corrected full reanalysis and reproduction passed |
| C++ formatting | Isolated clang-format23.1.3, LLVM-based style,4-space indent,100-column limit,include order retained | Leave minified diagnostic source |Readable diagnostic code; rebuilt main executable hashes matched the measured executables; no production formatting |

No optimisation implementation, new physics, tolerance change, native lock removal, density cache or time/position approximation is included.
